Quick start

  1. Install Square Sync & Pay for Odoo and open Square → Configuration.
  2. Choose Sandbox or Production, then click Connect with Square.
  3. Click Fetch Locations and map warehouses.
  4. Use Import from Square or Push to Square for catalog sync.
  5. Enable the Square payment provider on Website and POS as needed.
